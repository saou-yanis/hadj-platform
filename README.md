1st version

Ce projet a été étendu avec une version PHP sans base de données.

Pages principales :
- `index.php`
- `signup.php`
- `login.php`
- `results.php`
- `logout.php`
- `user-space/` pour le tableau de bord utilisateur et la gestion des tirages
- `admin-space/` pour la gestion des utilisateurs et des tirages

Pour tester localement, utilisez un serveur PHP depuis la racine du projet :

```powershell
php -S localhost:8000
```

Puis ouvrez `http://localhost:8000/index.php`.
